# 后续需求

## 触控模式热切换

状态：待实现。

在串流侧栏实时切换相对触摸板、绝对鼠标模拟和原生多点触控，不重新连接，不重建解码器。切换前取消旧触点、长按/拖拽定时器及已按下的鼠标按钮；同步本地缩放手势、屏幕控制器可用状态和设置保存。实现后将触控模式加入实时设置列表。

## 原生多点触控透传

状态：待实现。

新增“原生多点触控”模式，使用现有 LiSendTouchEvent 协议将多个手指的独立触点发送给 Windows。现有触摸板和绝对鼠标模拟模式保留。

- 服务端需启用 native_pen_touch，输入后端提供触摸屏能力；客户端结合 LI_FF_PEN_TOUCH_EVENTS 能力协商决定是否启用。
- 每个手指在按下、移动、抬起、取消期间保持独立、稳定的 pointer ID。
- 坐标按当前视频区域归一化，适应实时分辨率变化、横竖屏和折叠区域。
- 原生模式下，多指事件发送给远程应用，本地双指画面缩放与三指键盘手势不得抢占。
- 设置面板、屏幕控制器等本地操作不透传；切换模式、失去焦点、布局变化和退出串流时取消残留触点。
- 验收双指缩放/滚动、多指同时按下、触点取消及不支持主机的兼容行为；是否响应手势取决于远程应用。
