# 触控热设置与设备按钮

设备列表的“全部设备”筛选按钮和详情页的“应用管理”按钮使用蓝色文字、浅蓝色底和描边，呈现明确的可操作状态。详情功能栏依次显示“文件”“只看副屏”“无线副屏”“更多”，按实际按钮数量均分宽度；暂不显示观看模式和终端。

快速启动列表移除“添加应用”卡片，应用选择统一从“应用管理”进入。长按应用仅在手势开始时打开已有操作菜单；鼠标右键仍可打开。菜单展示、显示和关闭转场期间阻止重复展示，关闭完成后可以重新打开。

普通桌面和应用入口固定使用主显示器。串流设置中移除目标选择，在桌面下方提供两个独立副屏入口：“只看副屏”请求现有 `secondary` 模式，串流副屏并熄灭主屏；“无线副屏”请求现有 `extend` 模式，将客户端作为扩展屏并保持主屏正常使用。两个入口都不修改全局目标偏好，进入副屏后再启动普通桌面仍使用主显示器。保留服务端能力和可用状态检查及拒绝提示，不将不可用的副屏请求静默回退到主屏。

串流热设置显示现有的“触摸板”和“触摸屏”两种触控模式，切换立即保存到现有设置字段并应用到当前串流。原生多点触控仍延期。

两种模式共用同一个视频视图和滚动容器，不重新连接或重建解码器。触摸屏模式启用本地双指缩放/平移并禁用屏幕控制器；触摸板模式禁用本地缩放/平移，恢复保存的屏幕控制器等级。切换时复位缩放与偏移，释放旧模式的鼠标按键，取消长按、拖拽和延迟点击，等待原有手指抬起后才接受新手势。

打开设置、失去焦点、视频区域变化和退出串流时清理触摸输入，避免旧手势残留。验证包含生产对象中的热设置保存、控制器显示、按键和定时器清理、旧触摸事件屏蔽、缩放复位及反复切换时串流对象的稳定性。

验证：`BuildScripts/check-touch-modes.sh` 在 iPhone/iPad 模拟器加载生产对象，覆盖上述输入状态、主屏默认入口、两个副屏入口及各自的 launch/resume 请求参数、离线状态、旧偏好隔离及设置目标移除；同时验证单次长按、右键、菜单展示期间快速重复触发、关闭转场期间去重及关闭后重新打开。原有串流协议和键盘检查通过。iOS Debug 模拟器、签名 iOS Release、tvOS Debug 模拟器构建通过，已检查 iPhone/iPad 设备详情布局。真实主机上的副屏串流、主屏熄屏/恢复、无线副屏创建和远程手势未实测。
