# 串流键盘与快捷键

右侧功能区的“键盘”是显示/收起系统键盘的操作，不切换左侧内容。新增“快捷键”功能入口，由独立 KeyboardShortcutsViewController 管理左侧列表和编辑子控制器，继续复用现有串流设置容器及折叠屏工作区。

快捷键支持名称、Ctrl/Alt/Shift/Win 修饰键与一个主按键，用户确认首版不需要宏。主按键包含字母、数字、F1–F24、方向键和常用控制键。提供常用组合，用户可新增、编辑、删除自定义组合。本机保存，不发送名称或配置到服务端。

系统键盘上方的工具栏改为 KeyboardShortcutBar，使用横向滚动视图和按键栈，宽度由系统输入附属视图决定，避免采用视频区域尺寸导致窄屏、横屏和折叠区域下的按钮压缩。收起键盘按钮固定在尾部，其他按键与快捷键可左右滚动。工具栏保留 Win/Ctrl/Alt/Shift 锁定、Esc/Tab/Delete，并实时读取同一份快捷键存储。移除系统默认输入辅助按钮组，避免与自定义工具栏重复。

从按键上开始左右拖动时，滚动视图取消按钮的触摸跟踪并接管滑动，避免按钮占用手势或滑动结束时误触发快捷键。按键保留完整内容宽度，滚动内容裁剪在右侧收起键盘按钮之前；滑到末尾后，最后一个快捷键可完整显示。

本次修复验证：用户确认 iPhone 修复后可左右滑动；iPad 模拟器使用实际触摸滑动验证左右方向及滚到末尾，末尾按键右边界为 1077、滚动区域右边界为 1079、收起键盘按钮左边界为 1085，未发生遮挡。滑动期间没有触发按键，末尾快捷键与收起按钮点击均通过。键事件检查、iOS Debug 模拟器及签名 iOS Release 构建通过。

打开快捷键编辑器先收起远端输入键盘，名称文本框只进行本机编辑。组合键按修饰键按下、主键按下/释放、修饰键反序释放的顺序发送；键事件使用串行队列，50ms 主键按下时长不阻塞主线程。发送自定义组合前释放工具栏的锁定修饰键；关闭输入键盘也释放锁定状态。

检查组合键事件顺序及完整释放，存储重新加载、编辑、删除、重复/损坏记录处理；在 iPad、iPhone 与 Duo 串流预览中检查键盘切换、横向滚动、列表与编辑布局。构建 iOS Debug/签名 Release 及 tvOS，更新验收应用。真实串流输入由用户验收。

串流输入键盘弹出时自动关闭侧栏，点击浮动设置按钮会先收起串流键盘再打开侧栏。横屏手机和 iPad 使用键盘布局指南，将串流工作区限制在键盘及快捷键工具栏上方，复用视频现有的比例适配和触控坐标映射；键盘收起后恢复全屏。普通 iPhone 竖屏和 Duo 按折痕分区的竖屏保持原有视频布局，浮动设置按钮避让键盘。iPad 浮动键盘沿用系统布局指南的行为，不压缩整个工作区。快捷键页面输入名称属于本机编辑，保留侧栏；若空间不足，临时收起会话标题区并将名称框滚动到可见位置，保留编辑器的保存和取消操作。

已验证：组合键按下/反序释放及全部 16 种修饰键组合、F24、保存重载、编辑删除与损坏/重复记录检查通过；iPad 通过实际界面新增 Ctrl+Alt+Esc，验证重启后仍在、编辑成功、工具栏同步以及删除同步，并清理了验收样例。iPhone 横竖屏与 Duo 内屏竖屏已实际弹出软键盘，检查工具栏、键盘切换、列表和名称编辑；iPad 检查了外接键盘状态下的工具栏及横向滑动。截图位于 Build/KeyboardUI。iOS Debug、签名 Release 及 tvOS 构建通过，真实主机的按键效果由用户验收。

键盘避让增补：iOS Debug 模拟器构建通过。串流布局预览中确认 iPad 与 iPhone 横屏按原视频比例缩小，普通 iPhone 竖屏与 Duo 内屏竖屏保留原视频尺寸和位置；串流输入键盘打开后侧栏关闭，重新打开侧栏时键盘收起并恢复视频布局。Duo 操作区剩余高度不足时，浮动设置按钮移至键盘上方的可见区域。验收截图位于 Build/KeyboardViewportUI，实际远端桌面文字可读性由用户体验确认。
