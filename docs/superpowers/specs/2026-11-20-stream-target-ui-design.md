# 串流目标设置界面

## 已确认范围

在 iPhone/iPad 现有设置页增加“串流目标”，三个互斥选项如下：

| 目标 | 预期服务端行为 |
| --- | --- |
| 只连主屏幕（默认） | 串流主屏幕。 |
| 只连副屏幕 | 串流副屏幕，同时熄灭主屏幕。熄屏是此模式的固定行为。 |
| 无线副屏 | 将客户端作为电脑的无线扩展屏，主屏幕保持正常使用。 |

本阶段实现界面和本机保存。选项下显示“选择暂未生效，当前串流来源由主机决定”，不将预期行为显示为实际连接状态。

## 界面

新增区域位于分辨率设置之前。采用三个纵向单选卡片，包含图标、名称、说明和选中标记，沿用设置页的深色背景和紫色强调色。整个卡片可点击，支持 VoiceOver 选中状态和动态字体。iPhone/iPad 共用一套 UIKit 组件，按实际侧栏宽度换行。

选中项立即写入本机偏好，关闭设置、终止应用或重新打开后恢复。初次使用、未知或损坏的保存值回到主屏幕。设置沿用现有页面的全局作用域。

## 模块与数据

- `StreamTargetPreferences`：定义客户端内部的三个目标值，负责读取、验证和保存独立的应用偏好，不修改现有 Core Data 模型。
- `StreamTargetSettingsView`：只负责展示和选择，选择变化通过 `UIControlEventValueChanged` 通知设置控制器。
- `SettingsViewController`：加载偏好、处理保存，将新增区域加入现有滚动设置，按区域实际高度下移旧控件。
- 新增文案提供简体中文与英文资源，其他语言按应用默认英文回退。

三个保存值只用于客户端本机偏好，不作为尚未确定的服务端 API 字段。当前串流启动和网络请求保持现有行为；未来由服务端能力查询和会话配置接口读取所选目标，并报告实际应用结果。

tvOS 不增加选择入口，本阶段只验证共享项目仍可构建。

## 验证

1. 检查默认主屏幕、三个选项互斥、点击后保存、重新加载恢复，以及未知偏好的回退。
2. 检查 iPhone/iPad 的窄侧栏、横竖屏和较大字体下文字换行、可点击区域及滚动到最后一个旧设置。
3. 检查中英文文案及“暂未生效”提示。
4. 构建 iOS Debug/Release，并验证 tvOS 编译兼容性。
5. 确認本阶段不发送新增主机管理请求，不执行显示器切换、熄屏或虚拟屏操作。
