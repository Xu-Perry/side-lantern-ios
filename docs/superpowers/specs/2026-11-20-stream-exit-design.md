# 串流侧栏退出入口

用户要求在串流设置中增加明确的退出按钮，方便真机与模拟器操作。

“退出串流”固定在右侧功能栏底部、关闭设置按钮上方，使用红色图标和文字；不随左侧内容或功能菜单滚动，在串流、键盘、桌面三个 Tab 中均可见。原关闭按钮仅收起设置。首页 push 设置页面不显示串流退出操作。

SettingsSidebar 通过退出回调通知 StreamFrameViewController，复用 returnToMainFrame 流程：保存设置、关闭侧栏、恢复显示模式、取消统计定时器、返回首页，并通过现有控制器清理断开连接。按钮点击后禁用，避免重复触发。不发送退出主机应用的 cancel 请求。启动串流时的提示改为引导使用此按钮。

更新中英文文案和辅助功能标签，维持菜单顶部安全区、右边贴边和 Duo 副区域布局。用户决定自行测试，本轮只检查编译及资源，不操作模拟器界面、不连接主机，不再次测试拖动。
