# 串流侧栏只展示实时设置

用户要求串流中的设置只展示能热切换的项目，并移除说明文字。首页设置继续展示完整配置。

侧栏按当前会话能力展示分辨率、帧率、码率、屏幕控制器和串流统计。三项画质控件仅在 manual-video 当前会话可用时展示；屏幕控制器仅在本次串流使用相对触控模式时展示。其他设置、串流目标、分辨率摘要、生效说明和自动保存提示不挂载到串流设置视图。

每个设置行独立成组，能力变化时重新挂载允许的行；未展示的控件保留为首页复用模型，不参与侧栏布局和辅助功能树。串流侧栏只保存实际实时调整的统计、控制器和已确认视频参数，避免覆盖隐藏的启动配置。

正常状态不显示描述。应用中显示简短进度，实际失败显示简短失败状态；普通不支持状态通过隐藏相应控件处理。顶部退出操作和外部透明遮罩保持现有交互。编译后更新 iPad 与 Duo 模拟器，用户验收交互。

用户补充要求目标卡片只保留图标、标题和选中标记，删除行为说明、不可用原因和目标区域底部说明。能力校验仍在开始串流时执行。服务端当前 03b9ca3 的目标接口仍只能在 launch/resume 使用，未提供目标热切换，所以目标卡片仅出现在首页设置。

已完成 iOS Debug 模拟器、签名 iOS Release 和 tvOS Debug 模拟器构建；项目文件格式、git diff --check、中英文 90 个资源键检查通过。iPad 与 Duo 已更新并启动，安装的 Moonlight.debug.dylib 与本次构建一致。运行时页面验收由用户进行。
