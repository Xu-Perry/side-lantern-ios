# 串流侧栏与折叠屏操作区

## 用户确认的行为

- 普通 iPhone、iPad 和 iPhone Duo 横屏使用可收起的边缘设置侧栏。打开侧栏不改变主区域的尺寸、位置、视频比例或串流分辨率。
- iPhone Duo 竖屏内屏按系统提供的折痕区域划分：画面在主区域，虚拟操作与设置在副区域。两者在副区域内切换，打开设置不覆盖主区域。
- Duo 外屏采用普通 iPhone 行为，不增加内外屏同时显示功能。
- 串流中的设置入口是圆形浮动按钮；Duo 竖屏时该按钮位于副区域。
- 串流侧栏右侧底部提供常驻的“退出串流”按钮，与关闭设置分开；退出断开连接并返回首页，主机应用继续运行。详见 [串流侧栏退出设计](2026-11-20-stream-exit-design.md)。
- 侧栏增加功能区 Tab：“串流设置”“键盘设置”“显示桌面”。现有设置全部属于串流设置；另外两个 Tab 仅展示待实现状态，不执行远程操作。
- 功能菜单与内容采用左右结构：内容在左，竖向功能菜单贴紧屏幕右边。iPhone/iPad 横屏时侧栏及内容不为安全区额外留白，使用完整边界；Duo 竖屏仍在折痕下方显示该左右结构。
- 旋转和折叠只改变客户端布局，不中止连接，不重新协商分辨率。
- 功能菜单顶部保留安全区和横屏圆角避让，右侧仍贴边；串流侧栏保持完整边界。
- 圆形设置按钮可拖动，默认半透明，拖动、点击和操作时不透明。松手吸附最近的左右边缘，保存停靠位置；Duo 竖屏限制在副区域内，打开侧栏后在剩余可见区域停靠。拖动不触发设置点击或左边缘退出串流手势。
- 首页导航栏提供串流设置齿轮按钮，push 到 SettingsViewController，允许在连接前配置；串流内继续使用浮动按钮和侧栏。首页不使用旧 rear drawer。此项为用户最新要求，详见 [设置导航与生效时机](2026-11-20-settings-navigation-design.md)。

## 实现

设置通过子控制器嵌入串流侧栏，共用现有设置控件、持久化和主机能力查询；首页 push 同一设置 VC。侧栏内容使用完整边界，功能菜单顶部保留安全区与圆角避让，右侧贴边；主区域不参与侧栏布局。首页设置内容避开导航栏。

使用 iOS 27.1 的 `UIViewReservedRegion` division 查询读取折痕及其避让区域，包括展开状态下的 inactive 区域。只在竖屏、且系统提供折痕时分区；其他系统和设备沿用普通布局。保留当前串流对象，单独调整视频及虚拟操作的承载视图。控制器重排时释放按下状态，避免旋转后按键或摇杆卡住。

视频显示层随视频区域更新几何尺寸，继续保持与远程输入一致的宽高比例。屏幕数据从当前 window scene 读取。支持 manual-video 的会话可调整码率、帧率和编码分辨率，收到新关键帧后更新比例和触控映射，详见 [手动画质设计](2026-11-20-manual-video-design.md)。

圆形按钮具有设置图标、44 点以上点击区域和辅助功能标识。开启设置时仍可关闭设置；Duo 副区域在操作与设置间切换。统计显示和虚拟控制等级可立即应用；支持的会话可实时调整码率、帧率和分辨率，其他连接参数保存为下次连接设置，界面明确说明。

## 验证

模拟器检查普通 iPhone、iPad、Duo 的横竖屏，Duo 展开/半折叠、侧栏打开/关闭、虚拟控制区域和设置恢复。使用只在 Debug 模拟器启用的串流布局预览检查真实串流控制器的视图结构，不连接 Windows 主机。完成 iOS 构建及 tvOS 共享代码兼容检查，并更新 iPan。

已完成：普通 iPhone 的侧栏和两个待实现 Tab；iPad 侧栏末尾滚动和固定关闭按钮；Duo 横屏打开设置前后的画面边界一致；Duo 竖屏通过系统 scene geometry 与实际 division region 验证上下分区，设置打开前后视频边界一致。预览图片明确标示“串流布局预览”。iOS Debug 模拟器、签名 Release 和 tvOS Debug 模拟器构建通过，协议检查通过，中英文 64 个资源键一致。最终 Release 已更新到 iPan 并验证对应安装容器中的进程运行。Windows 串流联调仍由用户回家后进行。

最新左右结构已再次验证：iPhone 横屏的功能菜单按钮距离右边 6 点（菜单背景贴到屏幕边缘），左侧设置不保留安全区或旧抽屉预留宽度；iPad 的键盘/桌面占位与滚动后关闭可用；Duo 竖屏整个左右结构位于折痕下方。对应最终签名版本已安装并成功启动到 iPan。

菜单顶部避开圆角，右边仍贴边。按钮拖动由用户实测确认，按用户要求停止额外手势验证。用户随后恢复首页 push 串流设置入口，设置页逐项展示立即生效或下次连接生效，验证以最新设置导航设计为准。
