# 串流设置容器

用户明确要求独立的串流设置集合容器 VC，不同区域交给子 VC。界面移除右侧关闭按钮，透明全屏遮罩位于侧栏后方，点击侧栏外区域关闭设置。“退出串流”移动到左侧顶部操作区，右侧只保留串流、键盘、桌面分类。

`StreamSettingsContainerViewController` 管理全屏透明根视图、遮罩、侧栏位置以及子 VC 的包含关系。顶部会话操作区、右侧分类菜单和当前设置内容各自是子 VC。内容区复用现有 `SettingsViewController`；键盘、桌面使用独立的占位子 VC，后续可替换。顶部操作区承载标题和退出按钮，位于内容滚动区域之外。

现有 `SettingsSidebar` 保留为轻量协调接口，负责挂载容器、传递变更和退出回调。设置子 VC 直接属于容器；接入 Arrangement 后，容器属于工作区的操作子 VC，透明关闭遮罩挂载到全屏工作区。关闭容器保存设置并移除包含关系；退出按钮仍调用原有断开并返回首页流程。首页 push 的设置页保持独立，不包含串流操作区。详见 [Arrangement 布局](2026-11-20-stream-arrangement-design.md)。

遮罩透明，保留原视频尺寸和位置。侧栏覆盖遮罩，侧栏内点击不会关闭；侧栏外点击由遮罩消费，不发送到远程桌面。遮罩区域不激活旧的侧滑退出手势。Duo 竖屏侧栏继续位于折痕下方，遮罩覆盖整个串流工作区。右侧菜单顶部保留安全区和横屏圆角避让。

本次只变更上述容器和布局，不实现设置热切换。检查编译和源代码一致性，不操作用户正在使用的模拟器或串流会话。
