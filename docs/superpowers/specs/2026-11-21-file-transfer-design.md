# 文件传输

依据服务端 side-lantern-mvp 提交 6323184679d13f13d2af44af7b0238c339e8a227 及其文件传输接口文档，接入独立于串流会话的双向文件传输。入口位于已在线且已配对电脑的长按菜单，发现有效版本 1 能力后显示。

页面参考用户提供的两张图片：顶部显示电脑名称，三个圆形图标入口分别发送照片和视频、发送文件、浏览电脑文件。下方显示传输任务及按电脑保存的收发记录。发送使用系统 PHPicker 和 UIDocumentPicker，支持多选；接收记录支持预览、分享和保存到系统文件。清空记录确认后只清除记录，不删除用户已保存的文件。

电脑文件页只展示主机授权的共享位置，提供目录、上一级、分页和当前目录多选。宽屏左侧共享位置、右侧目录；窄屏依次进入共享列表与目录。选中下载后返回传输主页面查看进度。未开启、未授权、离线及空目录使用简洁的状态提示。

Foundation 协议模型验证 JSON、查询参数和二进制分块。HTTPS 复用 HttpManager 的客户端证书与主机证书验证，文件请求不跟随重定向。每台电脑拥有独立任务管理器及本机持久化目录，页面不持有传输生命周期。一次处理一个分块，上传上限 48 KiB、下载上限 1 MiB；在本地文件上读取和累积，不将整文件放进内存。

上传创建任务后按主机确认偏移发送，完成请求成功后确认已发送；暂停/断线恢复前查询上传状态。offset_mismatch 和请求结果不明时重新查主机偏移，过期任务重建。下载保存版本和本地字节数，恢复携带原版本；file_changed 时重试从头开始。暂停在当前分块结束后停下，取消停止后续请求并清理主机暂存任务。应用重启后将未完成任务恢复为暂停状态。

验证覆盖版本及错误响应、中文和加号编码、目录分页、上传与下载的数据完整性、空文件、暂停恢复、偏移不匹配、迟到响应、取消和持久化恢复。编译 iOS 模拟器及签名 Release，检查 iPhone、iPad 和 Duo 的页面布局；真实 Windows 收发由用户联调验收。
