# 120 FPS 串流选择

iPhone/iPad 的首页和当前串流设置均保留 30、60、120 FPS，不依据本地屏幕刷新率移除 120。iOS 启动串流时按用户选择提交帧率，manual-video 实时调整继续提交原值。

串流帧率与本地显示刷新率分别处理：渲染器启动及实时修改共用显示帧率更新方法，将 display link 目标限制在当前屏幕支持的范围；串流目标仍可为 120 FPS。tvOS 的既有启动限制保留。

完成编译后更新 iPad 和 Duo 模拟器供用户验收，不增加页面说明文字。

已完成 iOS Debug 模拟器、签名 iOS Release 和 tvOS Debug 模拟器构建。iPad 与 Duo 均已更新并启动，实际加载的调试库与本次构建一致；用户可验收 120 FPS 选择及串流请求。
